## Gaussian Splatting
 Our implementation of the paper "3D Gaussian Splatting for Real-Time Radiance Field Rendering"

## Obtaining the Code
Clone this repository *recursively* so that its submodules are also downloaded:

```
git clone --recurse-submodules https://github.com/maenneken/SaddlePointsElasticKnots.git
```
If it was already cloned
```
git submodule update --init --recursive
```
